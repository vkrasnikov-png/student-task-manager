# Student Task Manager

## Короткий опис

Student Task Manager — навчальний вебзастосунок для студентів вищих навчальних закладів та коледжів, який допомагає збирати завдання з різних дисциплін в одному місці та вчасно відстежувати найближчі дедлайни.

## Мета продукту

Допомогти студентам позбутися плутанини між різними навчальними платформами й чатами, зменшити кількість пропущених дедлайнів та оптимізувати планування часу під час семестру.
