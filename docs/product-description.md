# Опис програмного продукту

## Назва

Student Task Manager — вебзастосунок для планування та контролю навчальних завдань.

## Проблема

Студенти часто стикаються з великою кількістю лабораторних, практичних і курсових робіт з різних дисциплін. Використання паперових нотаток або розрізнених чатів призводить до пропуску дедлайнів, втрати інформації про вимоги до завдань та перевантаження наприкінці семестру.

## Цільова аудиторія

Студенти закладів вищої освіти, слухачі онлайн-курсів та учні старших класів, яким потрібен зручний інструмент для організації навчального процесу.

## Мета продукту

Забезпечити користувачеві єдиний структурований простір для обліку навчальних завдань, контролю термінів їх виконання та візуалізації власного прогресу протягом семестру.

## Основні функції

- створення, редагування та видалення навчальних завдань із зазначенням дисципліни та дедлайну;
- фільтрація та сортування завдань за статусом виконання, пріоритетом і предметом;
- відстеження наближення дедлайнів за допомогою візуальних індикаторів;
- перегляд статистики виконаних і запланованих робіт.

## Склад MVP

Базова версія продукту (MVP) включає головну сторінку зі списком завдань, форму додавання нового завдання (назва, предмет, дата здачі, пріоритет), можливість змінювати статус завдання («В процесі», «Виконано»), базову фільтрацію за статусом та збереження даних у локальному сховищі браузера (LocalStorage).
