# Activity-діаграма ключового процесу

## Загальна інформація

**Назва продукту:** Gamezone.

**Процес:** Знайти гру за назвою.

**Основний актор:** Гравець.

**Пов’язаний use case:** UC-01. Знайти гру за назвою.

**Мета процесу:** знайти потрібну гру в каталозі за повною або частковою назвою та відобразити її картку на екрані.
