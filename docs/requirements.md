# Вимоги до програмного продукту

## Загальна інформація

**Назва продукту:** Student Task Manager.

**Короткий опис:** вебзастосунок для обліку навчальних завдань, керування статусами виконання та контролю дедлайнів за дисциплінами.

**Цільова аудиторія:** студенти закладів вищої та фахової передвищої освіти.

---

## Функціональні вимоги

| ID | Назва вимоги | Опис вимоги | Пріоритет | Входить до MVP |
|:--|:--|:--|:--|:--:|
| FR-01 | Створення навчального завдання | Система повинна дозволяти студентові створити нове завдання із зазначенням назви, дисципліни, опису та дати дедлайну з подальшим збереженням у загальному списку. | Високий | Так |
| FR-02 | Перегляд списку завдань | Система повинна відображати список створених завдань із зазначенням назви, дисципліни, строку виконання та поточного статусу. | Високий | Так |
| FR-03 | Зміна статусу виконання завдання | Система повинна дозволяти студентові змінювати статус завдання (наприклад, «У роботі» або «Виконано») натисканням відповідного перемикача на картці завдання. | Високий | Так |
| FR-04 | Видалення завдання | Після підтвердження користувачем система повинна видаляти вибране завдання зі списку. | Середній | Так |
| FR-05 | Фільтрація завдань за дисципліною | Система повинна дозволяти студентові фільтрувати список завдань за обраною навчальною дисципліною або відображати всі завдання одночасно. | Низький | Ні |
