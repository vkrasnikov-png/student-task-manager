# Use-case модель програмного продукту

## Загальна інформація

**Назва продукту:** Gamezone.

**Основний актор:** Гравець (користувач каталогу).

**Додаткові актори:** відсутні.

## Опис акторів

**Гравець** — основний актор. Шукає ігри за назвою, фільтрує каталог за жанрами, переглядає детальну інформацію про обрані ігри та додає їх до списку «Обране».

## Основні випадки використання

1. Знайти гру за назвою (`FR-01`, `US-01`).
2. Відфільтрувати ігри за жанром (`FR-02`, `US-02`).
3. Переглянути детальну інформацію про гру (`FR-03`, `US-03`).
4. Додати гру до списку обраного (`FR-04`, `US-04`).
