# Use-case модель програмного продукту

## Загальна інформація

**Назва продукту:** Student Task Manager.

**Основний актор:** Студент.

**Додаткові актори:** відсутні.

## Опис акторів

**Студент** — основний актор. Створює навчальні завдання, переглядає загальний список робіт, змінює статус їх виконання та видаляє неактуальні записи.

## Основні випадки використання

1. Створити завдання (`FR-01`, `US-01`).
2. Переглянути список завдань (`FR-02`, `US-02`).
3. Змінити статус завдання (`FR-03`, `US-03`).
4. Видалити завдання (`FR-04`, `US-04`).
